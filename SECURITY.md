# Security Policy

## Supported Resources

Security reports concerning the Delaunay Book website and its directly
maintained machine-readable resources are accepted.

Relevant resources include:

- `https://delaunaybook.us/`
- website HTML;
- machine-readable metadata;
- XML feeds;
- sitemap resources;
- crawler configuration;
- publicly served project configuration.

## Reporting a Vulnerability

Please report suspected security vulnerabilities privately to:

contact@delaunaybook.us

Please include:

- a concise description;
- the affected URL or resource;
- reproduction steps;
- expected behaviour;
- observed behaviour;
- potential security impact;
- screenshots or logs where useful.

Do not include passwords, private keys, personal data or other sensitive
information unless it is strictly necessary.

## Coordinated Disclosure

Please allow reasonable time for investigation and remediation before public
disclosure.

The project may request additional information to reproduce and assess a
reported issue.

## Out of Scope

The following are generally not considered security vulnerabilities unless
they demonstrate a concrete security impact:

- purely cosmetic issues;
- broken links;
- spelling mistakes;
- unsupported browser behaviour;
- theoretical concerns without an exploitable consequence;
- content disagreements;
- ordinary crawler indexing behaviour.

## Security.txt

The canonical security contact information is also published through:

`/.well-known/security.txt`
