# Contributing

## Scope

Contributions to the Delaunay Book project may concern:

- website structure;
- accessibility;
- metadata;
- structured data;
- scholarly documentation;
- bibliographic information;
- machine-readable resources;
- documentation;
- security improvements;
- corrections to factual information.

## Before Contributing

Before submitting a change:

1. Verify factual claims against authoritative sources.
2. Check identifiers such as ISBNs and DOIs character by character.
3. Preserve existing canonical URLs unless a deliberate migration is being
   performed.
4. Validate XML documents after editing.
5. Validate JSON documents after editing.
6. Validate YAML-based metadata such as `CITATION.cff`.
7. Ensure that changes to one machine-readable representation do not introduce
   contradictions into another.

## Metadata Integrity

The following values should not be changed without a documented reason:

- canonical domain;
- author identity;
- DOI values;
- ISBN values;
- ORCID;
- publication language;
- publisher identity;
- canonical publication titles.

If a correction is required, explain the source of the correction.

## Content Corrections

Historical, bibliographical or scholarly corrections should include a
supporting source whenever possible.

Interpretive disagreements should be clearly distinguished from factual
corrections.

## Security Issues

Do not disclose security vulnerabilities publicly before they have been
reported to the project.

See `SECURITY.md`.

## Style

Use:

- UTF-8 encoding;
- LF line endings;
- valid standard syntax;
- meaningful headings;
- descriptive filenames;
- stable URLs;
- semantic HTML where applicable.

Avoid unnecessary tracking parameters and undocumented metadata.

## Pull Requests

A useful contribution should explain:

- what was changed;
- why it was changed;
- which files are affected;
- how the change was validated;
- whether any canonical identifier or URL changed.
