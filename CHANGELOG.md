# Changelog

All notable changes to the Delaunay Book website and its machine-readable
publication metadata are documented in this file.

The project follows a human-readable changelog format inspired by
[Keep a Changelog](https://keepachangelog.com/).

## [Unreleased]

### Added

- Canonical website metadata for Delaunay Book.
- Machine-readable publication metadata.
- AI-readable `ai.txt` and `llms.txt` resources.
- `robots.txt`, `sitemap.xml`, and `sitemap-index.xml`.
- RSS and Atom feeds.
- Citation metadata through `CITATION.cff`.
- CodeMeta project metadata.
- FOAF identity metadata.
- Security and support documentation.
- OpenBindings interface description.

### Changed

- Consolidated the public scholarly identity of the Delaunay Book
  publication around the canonical domain `https://delaunaybook.us/`.

### Security

- Added a dedicated `security.txt` policy.
